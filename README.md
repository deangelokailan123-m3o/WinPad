WinPad is a lightweight native text editor for Windows, developed by Kaiman18 Studios. Built in pure C using the Win32 API, WinPad focuses on being fast, simple, and lightweight without relying on large application frameworks.

WinPad 0.1 is the first public build, featuring a custom interface, file creation and editing, Open/Save support, UTF-8 text handling, keyboard shortcuts, word and line information, custom WinPad branding, and a Windows installer.

# Platform: Windows
